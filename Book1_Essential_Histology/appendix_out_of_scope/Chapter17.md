# Chapter 17 — The Urinary System

### Opening Question
How does kidney filter 180 liters a day and keep protein in blood?

### Why This Matters

### Big Picture
Kidney filters blood via glomerulus with 3-layer barrier then tubules modify filtrate via reabsorption/secretion. Barrier thin fluid but selective against protein size and charge.

### Core Concept
**Filtration barrier = fenestrated endothelium no diaphragm + GBM type IV network + laminin + perlecan negative charge + podocyte foot processes slit diaphragm nephrin. Thin ~300 nm prevents protein via size and negative charge.**
